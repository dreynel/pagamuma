# Hiligaynon Video Modules Directory

Place the 8 localized Hiligaynon video files (.mp4) directly inside this `video2/` folder on the new computer.

### Required File Names:
1. `pagamuma.mp4` — Introduction to PAG-AMUMA
2. `PinaSiglaTV _ Ep 1 Breastfeeding (Hiligaynon) _ APMC-SN Visayas.mp4` — Proper Breastfeeding (Hiligaynon)
3. `Pregstages.mp4` — Stages of Pregnancy (1st, 2nd, 3rd Trimester)
4. `Tipsforpreg.mp4` — Pregnancy Guidance & Avoiding Stress
5. `pregnancytips.mp4` — Health, Nutrition, and Self-care
6. `0903 (2).mp4` — Prenatal Care & Clinic Visits
7. `Copy of 0903 (1).mp4` — Comprehensive Motherhood Guide
8. `VID.mp4` — Quick Reminders for Early Pregnancy

> **Note**: Video files (`*.mp4`) are ignored by Git due to file size limits. Simply copy the `video2` folder or these 8 `.mp4` files from your source drive/USB into this directory.
